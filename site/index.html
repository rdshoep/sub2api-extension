两分钟装上

Install in two minutes

  1. 下载上面的 Chrome 或 Edge 安装包（zip），解压到一个固定目录。
  2. 打开 chrome://extensions 或 edge://extensions，打开右上角开发者模式。
  3. 点「加载已解压的扩展程序」，选中解压出来的文件夹。
  4. 把图标钉到工具栏，点开后到「实例」里填站点地址和管理员凭证。
  1. Download the Chrome or Edge zip and unzip it somewhere permanent.
  2. Open chrome://extensions or edge://extensions and enable Developer mode.
  3. Load unpacked and select the unzipped folder.
  4. Pin the icon, open Instances, and paste the site URL plus admin secret.

不经过 Chrome 网上应用店 / Edge 加载项也可以用：这就是开发者模式加载。商店上架需要 Sub2API 作者授权，沟通完成前请用本页安装包。

安全上怎么做的

How it treats your secrets

  • 没有 content script，不会改你正在看的网页。
  • 安装时不要全部网站权限；只有你添加某个实例时，才申请该站点的精确 origin。
  • 凭证默认记住且不锁密钥（推荐）；也可以给单个实例加密码，或只保存在当前会话。
  • 写余额 / 重置配额必须关掉只读，并填写原因。
  • No content scripts — the current page is untouched.
  • No all-sites permission at install; adding an instance requests that origin only.
  • Secrets are remembered without a password by default; optional per-instance lock or session-only.
  • Balance and quota writes need Allow Writes plus a reason.
